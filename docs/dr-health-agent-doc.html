Dr. Health · 家庭健康管理

一个家庭，共用资料目录。每位成员保留独立 Hermes profile，通过飞书交流，界面显示姓名。家属代问诊关联到被咨询成员，不增加家庭授权审批。

当前实现

成员与 profile 关联、按实际发生时间整理重复问诊、统一用药与体征数据、问诊阶段检查、资料核对、本地 PDF/OCR、就诊摘要和急诊卡。事件合并保留全部原始来源，支持拆分和重建。文件变更有备份、锁和原子保存。

家庭文件总览按姓名展示，成员目录支持按资料实际日期检索。同一份原文件保留一个正式条目和多次上传来源，差异单独标出；检查资料可关联问诊事件，随合并和拆分更新。支持归档恢复、按事件导出和原文件完整性检查。

认知观察统计与导入

Web 后台只保留认知统计和 JSON/CSV 数据导入，按姓名显示独立观察、九维聊天观察、本人/家属独立天数与复核提示。导入先校验和预览，再整批保存，重复提交不会增加计数。聊天分析由当前 Hermes 模型核对上下文与原句，本地只保存去原文结果；可选插件需明确启用。页面不展示一般健康资料或聊天原文，统计不代表疾病概率，认知提醒仅在 Web，不主动推送飞书。聊天分析与接入 · 模板、导入与使用说明 · 统计口径与医学边界

资料如何进入档案

原文件 → 按页提取 → 暂存 → 对照原文核对 → 入档并保留来源 → 成员报告。归档只影响目录展示，不删除临床事实。文字提取成功并不意味着医学解释正确。

能力边界

本仓库需要 Agent 宿主提供模型、网页工具或提醒调度。相互作用规则仅为有限演示，状态校验不构成医疗验证。本地存储不等于宿主本地推理。
